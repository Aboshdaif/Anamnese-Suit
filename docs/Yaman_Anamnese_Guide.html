📚 Schritt-für-Schritt Anleitung

1. Erste Schritte

Anwendung öffnen

Öffne die Datei medical_anamnesis.html in deinem Webbrowser (Chrome, Firefox, Safari oder Edge empfohlen).

Sprache wählen

Oben rechts findest du die Sprachauswahl. Du kannst zwischen Deutsch, Englisch, Türkisch, Russisch, Arabisch und vielen weiteren Sprachen wählen.

Fragebogen-Typ auswählen

Wähle den passenden Anamnese-Bereich: Vollständige Anamnese, Hausarzt, Orthopädie, Pädiatrie oder Geriatrie.

📸

Screenshot: Startbildschirm mit Sprachauswahl und Fragebogen-Typen

2. Fragebogen ausfüllen

Basisdaten eingeben

Beginne mit Vorname, Nachname, Geschlecht und Geburtsdatum. Diese Felder sind Pflichtfelder.

Fragen beantworten

Beantworte jede Frage sorgfältig. Der Fortschrittsbalken zeigt dir, wie weit du bist.

Navigation nutzen

Mit "Zurück" kannst du vorherige Antworten ändern. "Überspringen" ist bei optionalen Fragen möglich.

⚠️

Wichtiger Hinweis

Alle Daten bleiben lokal auf deinem Gerät. Es werden keine Daten an Server übertragen!

3. Daten exportieren

JSON Export

Nach Abschluss kannst du alle Daten als JSON-Datei herunterladen.

E-Mail versenden

Alternativ kannst du die Zusammenfassung direkt per E-Mail versenden.

📚 Step-by-Step Guide

1. Getting Started

Open Application

Open the file medical_anamnesis.html in your web browser (Chrome, Firefox, Safari or Edge recommended).

Select Language

In the top right corner, you'll find the language selection. You can choose between German, English, Turkish, Russian, Arabic and many more languages.

Choose Questionnaire Type

Select the appropriate anamnesis section: Complete History, General Practice, Orthopedics, Pediatrics or Geriatrics.

📸

Screenshot: Start screen with language selection and questionnaire types

2. Filling Out the Questionnaire

Enter Basic Data

Start with first name, last name, gender and date of birth. These are required fields.

Answer Questions

Answer each question carefully. The progress bar shows how far you've come.

Use Navigation

Use "Back" to change previous answers. "Skip" is available for optional questions.

⚠️

Important Note

All data stays locally on your device. No data is transmitted to servers!

3. Exporting Data

JSON Export

After completion, you can download all data as a JSON file.

Send Email

Alternatively, you can send the summary directly via email.

١. البداية

فتح التطبيق

افتحي الملف medical_anamnesis.html في متصفح الويب (يُنصح بـ Chrome أو Firefox أو Safari أو Edge).

٢. ملء الاستبيان

إدخال البيانات الأساسية

ابدأي بالاسم الأول واسم العائلة والجنس وتاريخ الميلاد. هذه حقول إلزامية.

الإجابة على الأسئلة

أجيبي على كل سؤال بعناية. شريط التقدم يُظهر مدى تقدمك.

استخدام التنقل

استخدمي "رجوع" لتغيير الإجابات السابقة. "تخطي" متاح للأسئلة الاختيارية.
