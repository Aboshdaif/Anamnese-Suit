✅ Was Chat Copilot kann

  • Fragen in normalem Deutsch beantworten
  • Code erklären und Fehler finden
  • Neue Funktionen schreiben
  • Dokumentation erstellen
  • Konzepte einfach erklären

⚠️ Grenzen & Wichtige Hinweise

  • Kann halluzinieren: Manchmal "erfindet" die KI Dinge, die nicht stimmen
  • Kein Ersatz für Fachwissen: Ärztliche Entscheidungen IMMER selbst treffen
  • Keine Patientendaten eingeben! DSGVO & Schweigepflicht beachten
  • Aktualität prüfen: Wissen kann veraltet sein

🎯 Best Practices

  • Kurz & klar: Präzise Fragen stellen
  • Kontext geben: Beschreiben Sie Ihr Ziel
  • Iterieren: Schritt für Schritt verfeinern
  • Prüfen: Ergebnisse immer kontrollieren

✅ What Chat Copilot can do

  • Answer questions in plain English
  • Explain code and find errors
  • Write new functions
  • Create documentation
  • Explain concepts simply

⚠️ Limitations & Important Notes

  • Can hallucinate: AI sometimes "invents" things that aren't true
  • No substitute for expertise: ALWAYS make medical decisions yourself
  • Never enter patient data! Observe GDPR & confidentiality
  • Check currency: Knowledge may be outdated

🎯 Best Practices

  • Short & clear: Ask precise questions
  • Give context: Describe your goal
  • Iterate: Refine step by step
  • Verify: Always check results

Aufgabe: [HIER DEIN ZIEL BESCHREIBEN] Anforderungen: - Alles in einer einzigen HTML-Datei, offline, keine externen CDNs/Fonts/Bilder - Klarer, einfacher Text auf Deutsch - Modernes, gut lesbares Design mit lokalem CSS - Keine echten Online-Aufrufe - Datenschutz beachten: Keine Patientendaten speichern/übertragen Liefere finalen HTML-Code (eine Datei) mit eingebettetem CSS/JS.

🏥 Radiologie-Prompts

Erstelle eine Checkliste für CT-Abdomen-Befundung: - Strukturierte Punkte für alle wichtigen Organe - Checkbox für "unauffällig" vs. "Auffälligkeit" - Platz für Freitext-Notizen - Alles offline in einer HTML-Datei - Keine Patientendaten, nur Struktur
Erstelle eine patientenverständliche Erläuterung für MRT-Untersuchungen: - Laienverständlich, kurze Sätze - Was passiert bei der Untersuchung? - Wie lange dauert es? - Worauf muss man achten? - Als druckbare HTML-Seite

💉 Diabetologie-Prompts

Erstelle einen Wochenplan für Blutzucker-Dokumentation: - Tabelle für 7 Tage - Spalten: Datum, Nüchtern, Nach Frühstück, Nach Mittag, Nach Abend, Bemerkungen - Nur Struktur, keine echten Werte - Druckbar, offline HTML
Erstelle eine Patienteninfo zu Hypoglykämie-Warnzeichen: - 6-8 Bulletpoints mit Symptomen - Einfache Sprache für Patienten - Was tun im Notfall? - Als übersichtliche HTML-Seite

🔧 Universal Prompt for Local HTML Apps

You are my assistant developer. Role: Senior engineer + privacy coach. Task: [DESCRIBE YOUR GOAL HERE] Requirements: - Everything in a single HTML file, offline, no external CDNs/fonts/images - Clear, simple text in English - Modern, readable design with local CSS - No real online calls - Privacy: Don't store/transmit patient data Provide final HTML code (one file) with embedded CSS/JS.

🏥 Radiology Prompts

Create a checklist for abdominal CT reporting: - Structured points for all major organs - Checkbox for "unremarkable" vs. "finding" - Space for free-text notes - All offline in one HTML file - No patient data, structure only
Create a patient-friendly explanation for MRI examinations: - Plain language, short sentences - What happens during the exam? - How long does it take? - What to pay attention to? - As printable HTML page

💉 Diabetology Prompts

Create a weekly plan for blood glucose documentation: - Table for 7 days - Columns: Date, Fasting, After Breakfast, After Lunch, After Dinner, Notes - Structure only, no real values - Printable, offline HTML

🏥 Medizinprodukt – Schnell-Check

Wann wird meine App zum Medizinprodukt?

Laut MDR (EU 2017/745) gilt Software als Medizinprodukt, wenn sie:

  • Diagnosen stellt oder unterstützt
  • Therapieentscheidungen trifft
  • Zur Überwachung von Patienten dient

→ Reine Dokumentations-Tools ohne Entscheidungsfunktion sind meist KEIN Medizinprodukt

Dies ist keine Rechtsberatung! Im Zweifel: Fachanwalt konsultieren.

✅ Sichere Nutzung

  • Nur strukturelle Vorlagen erstellen (keine echten Patientendaten)
  • Lokale HTML-Dateien nutzen (keine Cloud)
  • Pseudonymisierte Beispieldaten verwenden
  • Ergebnisse immer fachlich prüfen
🚫 NEVER enter in Copilot/Cloud tools:
  • Patient names, birth dates, addresses
  • Diagnoses with patient reference
  • Reports with identifiable data
  • Any PHI (Protected Health Information)

🏥 Medical Device – Quick Check

When does my app become a medical device?

According to MDR (EU 2017/745), software is a medical device if it:

  • Makes or supports diagnoses
  • Makes therapy decisions
  • Serves to monitor patients

→ Pure documentation tools without decision function are usually NOT medical devices

This is not legal advice! When in doubt: consult a specialist lawyer.

✅ Safe Usage

  • Only create structural templates (no real patient data)
  • Use local HTML files (no cloud)
  • Use pseudonymized example data
  • Always verify results professionally
